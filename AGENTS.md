# AGENTS.md

This repository is in its initial planning stage. Use [CONTRIBUTING.md](CONTRIBUTING.md) for the current contribution workflow and repository expectations.

## Current project status

The project has not implemented a production simulation yet. The team is using this repository to capture the early requirements, design direction, risk register, and planning decisions for a Unity-first Mars rover prototype.

## Tooling and runtime direction

Prefer a Unity-centric architecture for prototype development and product exploration. Gazebo and ROS are intentionally not the main technology stack at this checkpoint.

## Required files
